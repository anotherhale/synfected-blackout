# ADR-0002: Hybrid World Interaction

- Status: Accepted for BLACKOUT
- Date: 2026-11-19

## Context
BLACKOUT should feel like a Resistance facility rather than a menu-driven lobby, without sacrificing speed or accessibility.

## Decision
Adopt physical facility stations, contextual prompts, a context/role-aware radial menu, and conventional overlays for essential match information, confirmation, settings, and accessibility. Visual direction is cyberpunk Resistance technology: near-black surfaces, neon teal primary accent, terminal green success, crimson alerts, muted secondary text, restrained holographic effects.

## Consequences
Build reusable interaction components; keep authorization separate from UI; support keyboard/mouse, controller, and touch; never expose hidden role data; never make essential information terminal-only. Prioritize interaction framework, operations board, armory, and match HUD; defer elaborate progression displays if core loop is at risk.
