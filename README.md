## Status vocabulary
FOUNDATIONAL = established franchise direction. APPROVED FOR BLACKOUT = adopted project decision. PROPOSED = requires validation. EXPLORATORY = uncommitted. IMPLEMENTED = verified in code/runtime with evidence.

## Principles
- Server-authoritative gameplay; clients send intent, server validates.
- Hybrid in-world interactions plus overlays and radial quick access.
- Cyberpunk Resistance visual identity.
- Accessible, age-appropriate Roblox experience.
- Small independently verifiable tasks and independent QA.
- No runtime LLM dependency in MVP.
- Original creative expression; inspiration is not permission to copy protected content.

A plan, issue, or design document is not proof of implementation.
